
# EPP Ferretería Industrial

## Descripción
Aplicación web orientada a la comercialización y
visualización de productos de ferretería industrial
y equipos de protección personal (EPP).

## Funcionalidades
- Visualización del catálogo de productos.
- Búsqueda de productos por nombre.
- Filtrado de productos por categorías.
- Interfaz de navegación intuitiva.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
